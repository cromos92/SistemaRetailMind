🚀 CÓMO USAR EL SISTEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Iniciar Servidor
   └── python manage.py runserver

2. Acceder al Sistema
   └── http://localhost:8000/app/verGestionProducto/

3. Editar Producto
   └── Buscar → Botón "Editar" → Modal de Edición

4. Ajustar Stock
   └── Pestaña "Variaciones" → "Ajustar Stock" → ENTRADA/SALIDA

5. Ver Historial
   └── Pestaña "Variaciones" → "Ver Historial"
