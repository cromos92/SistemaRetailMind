## 🎯 4 FORMAS DE EDITAR (Elige la que prefieras)

### **Opción 1: Por Descuento %**
```
Campo: Desc. %
Escribes: 20
Resultado:
  Precio Original: $60,000
  Descuento 20%: -$12,000
  Precio Nuevo: $48,000
```

### **Opción 2: Por Descuento en $**
```
Campo: Desc. $
Escribes: 15000
Resultado:
  Precio Original: $60,000
  Descuento: -$15,000
  Precio Nuevo: $45,000
```

### **Opción 3: Precio Nuevo Directo**
```
Campo: Precio Nuevo
Escribes: 49990
Resultado:
  Precio Original: $60,000
  Precio Nuevo: $49,990
  Descuento: -16.7%
```

### **Opción 4: Por Margen Objetivo**
```
Campo: Margen Objetivo %
Escribes: 30
Sistema calcula:
  Costo: $35,000
  Margen deseado: 30%
  Precio = 35000 / (1 - 0.30) = $50,000
```
