Instrucciones:
  • Selecciona cómo deseas identificar a los proveedores: por RUT o por ID
  • Descarga el formato o exporta tus DTEs actuales para editarlos
  • Completa el archivo con los datos de tus DTEs de compras
  • Campos obligatorios: identificador de proveedor (RUT o ID), número de documento y monto_con_iva
  • El RUT debe estar en formato: 76123456-7 (sin puntos, solo guión)
  • Usa el monto con IVA (monto total de la factura) - el sistema calculará el neto automáticamente
  • También puedes usar monto_neto si lo prefieres - el sistema calculará el total
  • El campo responsable no es necesario - se asignará automáticamente tu usuario
  • El campo receptor (tu empresa) se asigna automáticamente
  • Todos los DTEs se importan con estado de pago "Pendiente" para que registres los pagos después
  • Los proveedores deben existir previamente en el sistema
  • Formatos aceptados: CSV (.csv), Excel (.xlsx, .xls)
